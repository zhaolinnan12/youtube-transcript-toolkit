YouTube Transcript Toolkit

Node.js CLI, subtitle format specifications, tested Regex cleanup recipes, and timestamp-overhead CSV datasets for working with YouTube captions across SRT, WebVTT, plain text, and Obsidian Markdown.

GitHub Repository npm: cleantranscript-cli Browser Tool (CleanTranscript)

Quick Start (CLI)

Requires Node.js 18+ with zero external dependencies. Works on .json3, .srt, rolling yt-dlp .vtt files, and raw text copied from YouTube's transcript panel.

# Install globally from npm
npm install -g cleantranscript-cli

# Strip timestamps and merge broken lines from raw YouTube panel text
cat raw-transcript.txt | yt-caption-clean --no-timestamps --join

# Convert a rolling yt-dlp .vtt file into Obsidian Markdown with YAML frontmatter
yt-caption-clean captions.en.vtt -f md --obsidian-yaml --title "Talk Title" --url "https://www.youtube.com/watch?v=jNQXAC9IVRw"

# Convert YouTube json3 captions to valid SubRip (.srt)
yt-caption-clean captions.json3 -f srt > captions.srt

Regex Cleanup Cheatsheet

Tested Find & Replace patterns for VS Code, Obsidian, and Google Docs. Raw CSV: data/timestamp-cleanup-regex.csv

Source Format Find (Regex) Replace Purpose
YouTube Panel (standalone) ^\s*\d{1,2}:\d{2}(?::\d{2})?\s*$\n? (empty) Strips 0:05 and 1:24:09 rows
Inline bracketed timecodes \[\d{1,2}:\d{2}(?::\d{2})?\]\s* (empty) Strips [04:18] prefixes
SubRip (.srt) cues ^\d+\r?\n\d{2}:\d{2}:\d{2},\d{3}\s-->\s\d{2}:\d{2}:\d{2},\d{3}.*$ (empty) Strips cue numbers and SRT timing lines
WebVTT inline <c> tags </?(?:c|v|b|i|u)(?:[^>]*)> (empty) Removes rolling auto-caption tags from yt-dlp VTT
Broken single newlines \r?\n+ (space) Joins 2–4s fragments into continuous prose

Browser Version

If you want to fetch existing public YouTube caption tracks directly in the browser and export SRT, WebVTT, plain text, or Obsidian-ready Markdown without local setup, use CleanTranscript. It reads existing creator or auto-generated caption tracks only and does not transcribe raw audio.
